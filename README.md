# 斗地主 PWA（doudizhu-pwa）

DaoBox 家族第 14 个应用：经典斗地主（单人 + AI 对手）+ 残局闯关（明牌解谜）。

## 玩法

### 经典模式

- 三人各 17 张，叫分（1/2/3 分）最高者当地主，拿 3 张底牌（20 张）
- 牌型：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子（五张起）/ 连对（三对起）/ 飞机（可带翼）/ 炸弹 / 王炸
- 大小：3<4<…<K<A<2<小王<大王；炸弹、王炸翻倍
- 结算：地主赢 ±2×底分×倍数，农民各 ±底分×倍数；积分本机累计

### 残局闯关

- 12 关难度递增，三家手牌全明（明牌残局），你（地主）先出，出完即胜
- 全部关卡经博弈树求解器验证：存在必胜路线，且非一手秒解
- 「提示」按钮实时调用内置求解器，直接标出必胜着法（绿色虚线）

## 技术栈

- 纯前端 PWA（零服务器对战成本）：原生 HTML/CSS/JS
- `rules.js` 规则引擎（牌型判定/比较/跟牌生成，4000 轮随机压测 + 子集枚举完备性验证）
- `ai.js` 启发式 AI（叫分估值/最小代价跟牌/农民不压队友/炸弹惜用）
- `tools/solver.mjs` 博弈树求解器（记忆化，与暴力参照 300 局全对拍）
- `tools/gen-puzzles.mjs` 关卡生成器（随机发牌 → 求解器验证必胜 → 输出 `public/puzzles.js`）
- 牌局进度/积分/关卡解锁 localStorage 本机存档
- 接入 DaoBox portal 时长体系（游客 15 分/天、注册 30 分/天，邀好友可加时）

## 本地开发

```bash
node server/node-server.mjs   # http://127.0.0.1:8803
node tools/gen-puzzles.mjs    # 重新生成残局关卡
```
